# 腹部疾病外部影像链接核查

2026-09-27 对用户提供的《新建 DOC 文档.doc》和《病例链接核查表.csv》逐行配对，共 268 行。DOC 与 CSV 均作为待核验线索，不作为正确性或转载许可证明。

`verified-abdomen-image-links.json` 只收录经站内疾病名称匹配、原站页面标题核对、确认原站提供影像预览或图版的链接。现有 73 个站内条目对应 75 条外部链接。论文中的病理或内镜图会在链接说明中标出，不冒充 CT/MRI。外部链接不计入站内配图数量，也不缓存、热链或复制原站图片。

核查时发现一些原表建议链接与病例不符。例如，“继发性硬化性胆管炎”建议链接指向 Klatskin 肿瘤；若干 PMC 编号打开了与疾病无关的论文。这些链接未入库。其他未核实的行仍需逐一寻找确切病例和图版，不应批量推断。

结构：`linksByRecordId` 以站内疾病 ID 为键，每条链接记录原站地址、页面标题、来源、影像证据说明和核查日期。更新时应重新打开原站，确认诊断、部位、图像及跳转仍然一致。
